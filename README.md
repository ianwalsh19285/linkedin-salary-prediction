# LinkedIn Job Salary Modeling

Machine learning project using LinkedIn job-posting data to classify jobs into lower-, middle-, and upper-salary categories from text, job metadata, and location features.

* **Ian Walsh**
* **Logan Rosell**

### Repo Structure
```text
├── data/
│   └── source_data_zstd.parquet   # Compressed dataset (ZSTD compression)
├── Linkedin_Job_Postings.qmd      # Quarto document containing full analysis & code
├── requirements.txt               # Python package dependencies
└── README.md                      # Project documentation
```
